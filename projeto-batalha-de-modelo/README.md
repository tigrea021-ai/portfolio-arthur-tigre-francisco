# ⚔️ Batalha de Modelos & Engenharia de Prompt (XML)

Projeto acadêmico desenvolvido com foco em Engenharia de Prompt, comparação entre modelos de Inteligência Artificial e geração automatizada de páginas HTML utilizando prompts estruturados em XML.

---

# 📌 Sobre o Projeto

O objetivo deste experimento foi criar um Prompt Estruturado em XML capaz de gerar uma página HTML Single Page com CSS integrado.

O mesmo prompt foi testado em diferentes modelos de IA para analisar:

* Precisão do resultado
* Qualidade do código HTML/CSS
* Criatividade visual
* Quantidade de bugs
* Consumo de tokens
* Interpretação da estrutura XML

# 📖 Considerações Finais

Este experimento demonstrou que a Engenharia de Prompt possui grande influência na qualidade das respostas produzidas por Inteligências Artificiais.

Além disso, evidenciou que diferentes modelos interpretam instruções de maneiras distintas, impactando diretamente na criatividade, precisão e estrutura do código gerado.
