# 👁️ Laboratório de Classificação Visual

Projeto desenvolvido utilizando Inteligência Artificial para reconhecimento e classificação visual de imagens através da plataforma Google Teachable Machine.

---

# 📌 Sobre o Projeto

Este projeto foi criado com o objetivo de explorar conceitos de visão computacional e aprendizado de máquina, treinando um modelo capaz de identificar padrões visuais e classificar imagens em categorias específicas.

O experimento também aborda questões relacionadas à ética, viés algorítmico e impactos sociais causados pelo uso de sistemas de Inteligência Artificial.

# ⚖️ Impacto e Ética

## Mecanismo do Viés

Quando um sistema é treinado com poucas imagens ou dados limitados, ele passa a aprender padrões reduzidos da realidade. Isso pode fazer com que o algoritmo tome decisões baseadas em generalizações e apresente erros em situações diferentes das utilizadas no treinamento.

## Consequência Social

Os erros de classificação podem impactar pessoas diretamente, causando exclusão, julgamentos incorretos e reforço de estereótipos sociais. Em ambientes profissionais e tecnológicos, isso pode gerar desigualdades e limitar oportunidades.

## Ação Mitigadora

Uma das soluções é utilizar o modelo Human-in-the-loop, no qual pessoas acompanham, revisam e corrigem os dados utilizados pela IA. Isso ajuda a reduzir vieses e tornar o sistema mais justo e equilibrado.
